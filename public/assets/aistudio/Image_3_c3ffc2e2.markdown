## Brand & Style

The design system establishes a high-caliber digital developer studio presence tailored for an elite AI/ML engineer. It merges the structural precision of high-end computational research labs with the fluid restraint of modern avant-garde editorial design.

### Brand Personality & Core Mood
- **Intellectual Rigor:** Grounded, analytical, and uncompromising in technical depth.
- **Architectural Minimalism:** Generous negative space, calibrated grid systems, and functional structural framing over superficial decoration.
- **Luminous Cybernetics:** Deep obsidian surfaces illuminated by disciplined flashes of chromatic energy, evoking advanced neural architectures, hyper-modern compute clusters, and scientific clarity.

### Target Audience
Engineering leaders, autonomous systems researchers, venture scouts, technical recruiters, and open-source collaborators seeking an engineer with both bleeding-edge AI expertise and world-class product craftsmanship.

### Visual Language
The aesthetic fuses **Digital Editorial Minimalism** with **Technical Blueprint Architecture**. Layouts rely on clean structural divides, micro-monospace datums, precise hairline borders, and subtle glass-surface refraction. Accents in electric cyan and soft violet are deployed with surgical restraint—acting solely as focal anchors, terminal prompts, and active state indicators rather than saturated fills.

## Colors

The palette operates on a strict luminescence hierarchy engineered specifically for low-light legibility and cinematic contrast.

### Palette Architecture
- **Canvas Base (`#080B12`):** Ultra-deep cosmic obsidian providing infinite visual depth and zero OLED light spill.
- **Surface Elevation (`#101521`):** Subtle lifted background for alternating rhythm sections, nested sidebars, and structural wells.
- **Card / Surface Floating (`#141C2A`):** The primary container tone for project showcases, benchmark cards, and interactive consoles.
- **Structural Boundary (`#263044`):** Hairline delimiter tone creating razor-sharp containment without drawing high-contrast visual noise.
- **Primary Text (`#F5F7FA`):** High-emittance crisp chalk white ensuring total legibility across deep substrates.
- **Secondary Text (`#A5ADBA`):** Muted slate providing balanced tonal de-emphasis for body metadata, descriptions, and supporting prose.
- **Primary Accent (`#8B7CFF` - Soft Violet):** Cognitive highlight color reserved for primary call-to-actions, active navigation markers, and core AI model badges.
- **Secondary Accent (`#48D9D0` - Electric Cyan):** Kinetic signal color denoting live server statuses, system pings, real-time metrics, and hyperlinked inline elements.

### Color Rules & Application Ratios
- Apply an **85-10-5 rule**: 85% Canvas & Card dark tones (`#080B12`, `#141C2A`), 10% Neutral boundary & supporting text (`#263044`, `#A5ADBA`), and 5% combined chromatic accents (`#8B7CFF`, `#48D9D0`).
- Never use solid accent fills for sprawling card backgrounds. Accents must live as hairline borders on hover, glowing anchor blurs, micro-pill indicators, gradient text selections, or cursor-reactive sparks.

## Typography

The typographic hierarchy implements an intentional three-tiered system to reflect the intersection of human-computer interaction, academic publication, and raw computational code.

### Font Roles
- **Headlines & Editorial Statements (`Space Grotesk`):** Chosen for its idiosyncratic geometric nuances and technical futurism. Used for section anchors, case study titles, and key value statements. Tight letter spacing (`-0.02em` to `-0.04em`) produces an authoritative, modern poster aesthetic.
- **Body & Longform Reading (`Inter`):** Neutral, optically balanced, and comfortable for extended narrative review. Handles project retrospectives, architecture summaries, and experience write-ups.
- **Technical Metrics & Micro-Copy (`JetBrains Mono`):** Monospaced precision for system metadata, code snippets, Git telemetry, algorithmic benchmark metrics, and status pills. Always uppercase when used for section indices (e.g., `// 01. NEURAL ARCHITECTURES`).

## Layout & Spacing

The layout is grounded in a clean 12-column architectural grid with dynamic spacing tailored for responsive presentation across mobile, tablet, and widescreen devices.

### Grid System
- **Mobile (< 768px):** 4-column layout with `1rem` margins and `1rem` gutters. Content cascades linearly with stacked card modules and compact headers.
- **Tablet (768px - 1024px):** 8-column layout with `2rem` margins and `1.5rem` gutters. Allows dual-column metric breakouts and hybrid preview cards.
- **Desktop (>= 1024px):** 12-column layout capped at a maximum container width of `1280px` centered within the viewport. Outer margin defaults to `3rem` with `2rem` column gutters.

### Layout Philosophy
Sections employ an asymmetric layout balance: prominent left-aligned headline columns paired with expansive project showcases on the right. Large vertical offsets (`space-2xl` and `space-3xl`) isolate concepts, ensuring research papers and machine learning demos possess distinct visual air.

## Elevation & Depth

This design system avoids heavy skeuomorphic drop shadows. Depth is achieved via **Tonal Layering**, **High-Precision Hairlines**, and **Luminous Back-Glows**.

### Surface Hierarchy
1. **Level 0 (Base Canvas):** `#080B12`. The infinite foundation.
2. **Level 1 (Sub-section / Side Panes):** `#101521` with `border: 1px solid #263044`.
3. **Level 2 (Interactive Floating Cards):** `#141C2A` with `border: 1px solid #263044`. Hover states reveal a gradient border transition toward `#8B7CFF` (30% opacity).
4. **Level 3 (Modals / Overlays / Code Consoles):** `#141C2A` backed by `backdrop-filter: blur(16px)` with 85% surface opacity and a micro-glow border (`box-shadow: 0 0 24px -4px rgba(139, 124, 255, 0.15)`).

### Luminous Atmosphere
Depth is accentuated using radial atmosphere nodes behind primary feature cards:
- An ultra-diffuse radial blur (`filter: blur(120px)`) using `#8B7CFF` at 8% opacity positioned behind hero titles and core AI model architecture diagrams.
- Active system nodes feature an electric cyan point glow (`#48D9D0` at 12% opacity) to convey live operational status.

## Shapes

The geometric framework utilizes a **Soft Industrial (0.25rem - 0.75rem)** rounding strategy. This sharp, controlled radius reinforces a computational, lab-grade developer environment rather than consumer-app softness.

### Corner Radius Allocations
- **Base Components (`rounded-sm` / `0.25rem`):** Badges, input toggles, status pills, inline code tags, and micro-buttons.
- **Standard Cards & Containers (`rounded-md` / `0.5rem`):** Repository cards, model benchmark tables, and interactive terminal windows.
- **Large Panels & Modals (`rounded-lg` / `0.75rem`):** Full-screen preview dialogs and showcase hero wrappers.
- **Pill Exception (`rounded-full`):** Strictly reserved for dynamic status dots and circular icon buttons.

## Components

### Buttons
- **Primary Action:** Solid background with soft violet `#8B7CFF`, text rendered in `#080B12` (bold `Space Grotesk`), `border-radius: 0.25rem`. On hover, surface triggers a soft neon bloom (`box-shadow: 0 0 20px rgba(139, 124, 255, 0.4)`).
- **Secondary (Technical Outline):** Background transparent, border `1px solid #263044`, text `#F5F7FA` (`JetBrains Mono`). On hover, border transitions to `#48D9D0` and background shifts to `rgba(72, 217, 208, 0.05)`.
- **Ghost Action:** Background transparent, text `#A5ADBA`. Transitions to `#F5F7FA` with an accompanying arrow translate (`translateX(4px)`) on hover.

### Chips & Badges
- **Model / Tag Chips:** Background `#101521`, border `1px solid #263044`, font `JetBrains Mono` (`label-mono-sm`), text `#A5ADBA`.
- **System Status Badge:** Inline flex container with a pulse dot (`#48D9D0`), text in `#48D9D0`, background `rgba(72, 217, 208, 0.08)`, border `1px solid rgba(72, 217, 208, 0.2)`.

### Cards & Project Showcases
- Containers are framed with `#141C2A` surfaces and `#263044` hairlines.
- Top card metadata header houses terminal-style dots or monospaced indices (`// ML-01 // TENSORFLOW`).
- Content displays title in `Space Grotesk` (`headline-sm`) followed by description in `Inter` (`body-sm`).
- Bottom rail hosts an array of tech chips and an external link anchor utilizing `#48D9D0`.

### Form Fields & Terminal Inputs
- **Inputs:** Background `#080B12`, border `1px solid #263044`, text `#F5F7FA`, placeholder `#A5ADBA` at 50% opacity. Focused state shifts border to `#8B7CFF` with a zero-offset outline glow (`box-shadow: 0 0 0 1px #8B7CFF`).
- **Terminal Console Input:** Prepended with `$` in `#48D9D0`, font `JetBrains Mono`.

### Lists & Technical Timelines
- Experience & education rows built on alternating transparent rows separated by `1px solid #263044`.
- Left column hosts dates and institution (`REVA University`) in `label-mono-md`, middle hosts degree/role in `Space Grotesk`, right hosts descriptive ML research accomplishments in `Inter`.

### Code Blocks & Architecture Visualizers
- Header bar in `#101521` featuring file path or model topology name (`model_trainer.py`).
- Body in `#080B12` with syntax highlighting tuned to match soft violet, cyan, and muted slate.
- Micro copy-to-clipboard action icon positioned in the top-right corner.
